# 📝 Blog Layout

A simple and responsive **Blog Layout** built using **HTML** and **CSS**. This project demonstrates the use of Flexbox, sticky navigation, dropdown menus, sidebars, and blog post cards.

---

## ✨ Features

- 📌 Sticky header navigation
- 📂 Hover-based dropdown menu
- 📰 Blog post cards with images
- 📖 "Read More" buttons
- 🔍 Sidebar with search bar
- 📑 Navigation links for Categories, Recent Posts, and Social Links
- 🎨 Clean layout using CSS Flexbox
- 💻 Beginner-friendly project structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Transitions

---

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/aryan6002261/blog.git
```

2. Navigate to the project folder:

```bash
cd blog
```

3. Open `blog.html` in your preferred web browser.

No installation or additional dependencies are required.
