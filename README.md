# 📝 Blog Layout

A modern and interactive **Blog Layout** built using **HTML**, **CSS**, and **JavaScript**. This project showcases a clean blog interface with a sticky navigation bar, dropdown menu, sidebar, blog cards, and interactive features such as live search, dark mode, and smooth animations.

---

## ✨ Features

- 📌 Sticky navigation header
- 📂 Hover-based dropdown menu
- 📰 Beautiful blog post cards with images
- 📖 Interactive **Read More** buttons
- 🔍 Live search to filter blog posts
- 🌙 Dark/Light mode toggle
- ⬆️ Smooth scroll-to-top button
- ✨ Fade-in animations on scroll
- 📑 Sidebar with Categories, Recent Posts, and Social Links
- 🎨 Clean Flexbox-based layout
- 💻 Beginner-friendly and easy to customize

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- CSS Flexbox
- CSS Transitions & Animations

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/aryan6002261/blog.git
```

2. Navigate to the project folder:

```bash
cd blog
```

3. Open `blog.html` in your preferred web browser.

No installation or additional dependencies are required.
